## Number pad, with room to move

Glide turns your phone into a Linux touchpad, with native multitouch gestures and a Rust + GTK4/libadwaita desktop app. This preview adds a desktop number pad and a compact shortcut sidebar.

### What’s new

- **Number pad:** digits, decimal separator, arithmetic, Enter, Backspace and Delete go to the focused desktop app as native keypad/editing keys. The decimal separator follows your desktop keyboard locale.
- **Landscape split:** a compact number pad on the left, with a live touchpad in the remaining space on the right. Typing keeps an ongoing touchpad contact active.
- **Pinned shortcuts:** open **Tools & shortcuts** to pin or unpin the number pad. Pins are saved per device on the desktop and can also be changed in desktop device settings.
- **Compact sidebar:** tap the Glide logo for fullscreen, preferences, disconnect and reconnect. A small dot shows connection status.
- **State-aware Num Lock:** opening the number pad checks Linux’s reported Num Lock LEDs and enables it only when consistently off. Already-on Num Lock stays on. Missing or inconsistent state is reported instead of guessing; if needed, enable Num Lock on your desktop keyboard.

This is a number pad, not a calculator. Existing cursor/scroll speeds, adjustable tap vibration and optional four-finger media controls remain available.

### Install or update

Download **Glide-0.1.9-x86_64.AppImage**. We recommend [Gear Lever](https://gearlever.mijorus.it/) for desktop integration and updates; [configure it for Glide](https://github.com/Stem-LG/Glide#gear-lever-recommended) and allow prereleases.

**Quit the running Glide instance before updating, reopen it, then refresh your phone’s page.** Existing pairings and device preferences are preserved. The number-pad shortcut is pinned by default.

```sh
chmod +x Glide-0.1.9-x86_64.AppImage
./Glide-0.1.9-x86_64.AppImage
```

If FUSE is unavailable, add `--appimage-extract-and-run`. The [one-time input setup](https://github.com/Stem-LG/Glide/blob/v0.1.9/data/setup/README.md) still applies. Run Glide as your normal user.

### Compatibility and validation

Portable **x86_64**, **glibc 2.35+**, with bundled GTK/libadwaita. The packaged AppImage passes version/startup, pairing, settings persistence and GTK window checks in Ubuntu 22.04, Ubuntu 24.04, Debian 12 and Fedora 44 runtime containers. These checks establish userspace loading and app behavior, not full desktop gesture compatibility on every distribution.

Rust tests, Clippy, JavaScript gesture/tool tests, network/pairing and per-device persistence checks pass. Native-input tests use exclusively grabbed test devices to verify keypad/media press-release pairs, Num Lock handling and simultaneous keypad/touchpad input. Portrait and landscape layouts were verified in a browser during development.

Native gestures depend on libinput and your desktop compositor. Use a trusted local network: the phone connection uses unencrypted HTTP/WebSocket. Licensed under GPL-3.0-or-later.

The AppImage is the runnable download. The corresponding-source archive includes application and dependency sources. Build metadata, dependency inventories and `SHA256SUMS` accompany this release.
