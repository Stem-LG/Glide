## Your phone. Your touchpad.

Glide turns your phone or tablet into a Linux touchpad through its browser, with
smooth multitouch gestures handled by libinput and GNOME. The desktop app is
built with Rust, GTK4, and libadwaita. No phone app, cloud service, or account.

This is the **first public preview**, released under **GPL-3.0-or-later**.

### Highlights

- A full-screen touch surface for movement, two-finger scrolling/pinch, and native
  three-finger GNOME navigation.
- QR-code connection and PIN pairing, with desktop device management.
- Independent cursor/scroll speeds and per-device preferences saved on the desktop.
- Balanced portrait/landscape movement, including continuous sweeps above 1×.
- A tray menu to reopen the app, background operation, and optional start at login.

### Download and run

Download **Glide-0.1.6-x86_64.AppImage**, then:

```sh
chmod +x Glide-0.1.6-x86_64.AppImage
./Glide-0.1.6-x86_64.AppImage
```

Run as your normal user. If input access is unavailable, follow the
[uinput setup guide](https://github.com/Stem-LG/Glide/blob/v0.1.6/data/setup/README.md).
Connect both devices to the same trusted network, scan the QR code, and enter
the desktop pairing PIN. If FUSE is unavailable, launch with
`--appimage-extract-and-run`.

### Compatibility and limits

Built and tested on **Fedora 44, GNOME 50, Wayland, x86_64**. Older Linux
installations may need a source build; this AppImage is not yet a universal
distro build. GNOME needs an AppIndicator extension to show the tray icon.

Use only on a **trusted LAN**. The current HTTP/WebSocket connection is
unencrypted; do not expose the port to the Internet. See the
[security model](https://github.com/Stem-LG/Glide/blob/v0.1.6/SECURITY.md).

### Assets

- **AppImage** — ready-to-run desktop application.
- **Glide-0.1.6-sources.tar.gz** — application source, locked Rust dependencies,
  native dependency source RPMs, and AppImage runtime sources/build recipe.
- **native-packages.tsv / rust-crates.tsv** — dependency inventories.
- **SHA256SUMS** — checksums for the downloads.

The source bundle is only needed for rebuilding/auditing. Installation, gestures,
preferences, troubleshooting, and build instructions are in the
[README](https://github.com/Stem-LG/Glide/tree/v0.1.6#readme).

Validation includes Rust tests, formatting/Clippy, browser JavaScript syntax,
isolated pairing/settings tests, and native libinput gesture/speed regression
checks. Actual phone control and tray reopening were also exercised on the
supported desktop. Testing on other distributions and browsers is welcome.
