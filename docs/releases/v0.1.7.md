## A more portable Glide

Glide turns your phone into a Linux touchpad, with a native GTK desktop app and a
browser controller. This preview replaces the Fedora-specific AppImage build
with an **Ubuntu 22.04 / glibc 2.35 baseline**, while bundling a newer GTK/libadwaita
UI stack built against that baseline.

### What's changed

- A portable **x86_64 AppImage targeting glibc 2.35 or newer**.
- Checksum-pinned UI dependencies built from source, with corresponding sources
  and license notices included in the release.
- Bundled image loaders for icons and SVGs.
- An automated check that rejects any bundled ELF requiring glibc newer than 2.35.
- Clean-container compatibility checks for the packaged app.

Cursor movement, native gestures, pairing, and saved per-device settings keep
the same behavior as 0.1.6.

### Install or update

Download **Glide-0.1.7-x86_64.AppImage**. We recommend
[Gear Lever](https://gearlever.mijorus.it/) for app-menu integration and updates;
[configure it for Glide](https://github.com/Stem-LG/Glide#gear-lever-recommended)
and enable preview releases. Quit the running Glide instance before updating,
then reopen it and refresh the phone page.

Manual launch:

```sh
chmod +x Glide-0.1.7-x86_64.AppImage
./Glide-0.1.7-x86_64.AppImage
```

Use `--appimage-extract-and-run` if FUSE is unavailable. The
[one-time uinput setup](https://github.com/Stem-LG/Glide/blob/v0.1.7/data/setup/README.md)
still applies; run Glide as your normal user.

### Validation

The same AppImage passed startup, pairing/origin checks, desktop-owned settings
persistence, and GTK window tests in clean Ubuntu 22.04, Ubuntu 24.04, Debian 12,
and Fedora 44 containers. The Ubuntu-rendered interface was also visually checked.
Rust tests and Clippy pass on the portable build baseline. The new GTK build
also starts on the host GNOME Wayland session. Native helper tests pass for
swipes, scrolling, pinch, watchdog release, full-surface movement above 1×, and
horizontal/vertical speed balance.

### Scope

This is a glibc-based Linux **x86_64** build, not an ARM or Alpine/musl build.
Native gestures depend on the desktop compositor and libinput. Full GNOME gesture
behavior remains verified on Fedora 44 / GNOME 50 / Wayland; a clean-container
GUI check on another distro is not a full desktop gesture test.

The HTTP/WebSocket connection remains unencrypted: trusted local networks only.
Glide is licensed under GPL-3.0-or-later.

### Assets

The AppImage is all you need to run Glide. The source archive includes application
and dependency sources for rebuilding/auditing. `build-info.json` records the
build baseline and upstream dependency hashes; the TSV files list dependencies.
`SHA256SUMS` covers the release downloads.
