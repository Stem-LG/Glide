## Sound, both ways

Glide turns your phone into a Linux touchpad, with native multitouch gestures and a Rust + GTK4/libadwaita desktop app. This preview adds desktop audio on your phone, your phone as a desktop microphone, and an optional encrypted connection.

### What’s new

- **Desktop audio:** hear your computer’s sound on the connected phone or tablet. It mirrors the default output, so mute the desktop speakers if you only want it on the phone. Playback keeps a small adaptive buffer; expect a short delay that depends mostly on your phone’s audio output (more over Bluetooth).
- **Phone microphone:** the connected device appears on the desktop as the **Glide phone microphone** input while the switch is on. Select it in the app you want to use it with.
- **Audio tool:** both switches live on a new pinnable **Audio** page beside the number pad, with live delay and buffer figures. Small status chips appear on the touchpad while audio or the microphone is on.
- **Secure connection (HTTPS):** a new desktop preference serves HTTPS on the same port with a certificate generated on your computer. Browsers require it for the microphone. Your phone shows a certificate warning once, and pairs again because the secure address counts as a new site; choose your existing profile to keep its settings. `--https` enables it for a headless run.

Everything is off by default and saved per device. Audio and the microphone stop when the phone page is hidden or disconnected, like touch input.

### Requirements

Desktop audio needs `pw-record` (PipeWire) or `parec` (PulseAudio) on the desktop. The phone microphone needs PipeWire’s `pw-cat`; there is no PulseAudio path for it yet. These tools are not bundled.

### Install or update

Download **Glide-0.1.10-x86_64.AppImage**. We recommend [Gear Lever](https://gearlever.mijorus.it/) for desktop integration and updates; [configure it for Glide](https://github.com/Stem-LG/Glide#gear-lever-recommended) and allow prereleases.

**Quit the running Glide instance before updating, reopen it, then refresh your phone’s page.** Existing pairings and device preferences are preserved.

```sh
chmod +x Glide-0.1.10-x86_64.AppImage
./Glide-0.1.10-x86_64.AppImage
```

If FUSE is unavailable, add `--appimage-extract-and-run`. The [one-time input setup](https://github.com/Stem-LG/Glide/blob/v0.1.10/data/setup/README.md) still applies. Run Glide as your normal user.

### Compatibility and validation

Portable **x86_64**, **glibc 2.35+**, with bundled GTK/libadwaita. The packaged AppImage passes version/startup, pairing, settings persistence and GTK window checks in Ubuntu 22.04, Ubuntu 24.04, Debian 12 and Fedora 44 runtime containers. These checks establish userspace loading and app behavior, not full desktop gesture compatibility on every distribution.

Rust tests, Clippy, JavaScript tests, and network checks covering the audio and microphone sockets and HTTPS on the same port pass. Native-input tests on exclusively grabbed test devices pass unchanged. Audio capture and the virtual microphone were exercised on a Fedora host with PipeWire 1.6 and used from one phone browser. Not yet verified: other PipeWire versions, the PulseAudio capture path, and iOS Safari with the self-signed certificate. Reports are welcome.

Use a trusted local network. Traffic is unencrypted unless Secure connection is on; the self-signed certificate protects against passive observers, not an active attacker at the first visit.
