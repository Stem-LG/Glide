## Four-finger media controls and adjustable haptics

Glide turns your phone into a Linux touchpad, with native gestures and a Rust +
GTK4/libadwaita desktop app. This preview adds optional media gestures and lets
you tune the vibration feedback to your phone.

### Four fingers, your media

Enable **Four-finger media controls** in the web Preferences or the desktop
app's device settings:

| Gesture | Action |
| --- | --- |
| Four-finger tap | Play / pause |
| Swipe up / down | Volume up / down, progressively |
| Swipe left / right | Previous / next track, once per gesture |

The toggle is **off by default** and saved per device. Place all four fingers
before moving; lift them all before starting another gesture. With media mode
on, Glide reserves up to 90 ms at the start to recognize the fingers. Native
movement can start sooner, and an existing desktop gesture is never switched to
media halfway through. With the toggle off, input goes directly to the desktop.

Media actions use standard Linux media keys. Your desktop's key bindings and
active player determine which application responds.

### Adjustable tap feedback

- Optional vibration for quick taps on supported phone browsers.
- A **5–100 ms pulse-duration slider**, defaulting to 25 ms.
- Preview the selected pulse as you adjust it, or press **Test vibration**.
- Preferences persist on the desktop and are editable from both interfaces.

Browser vibration support varies. Duration adjusts the pulse length, not motor
power; native Android keyboard click effects are not available through this API.

### Fixes and validation

Fixed a browser timer-binding error that stopped initialization and pairing in
an early media-controls preview. Fresh pairing, automatic reconnection after a
page refresh, and media-mode startup were verified in a real browser.

Rust tests, Clippy, browser gesture regression tests, network/pairing tests, and
per-device persistence checks pass. Isolated native-input tests verify media-key
press/release pairs and existing touchpad taps, scrolling, swipe and pinch behavior.
The versioned AppImage passes startup, network, settings and GTK window checks in
Ubuntu 22.04, Ubuntu 24.04, Debian 12 and Fedora 44 runtime containers. Container
checks do not establish full desktop gesture compatibility on each distribution.

### Install or update

Download **Glide-0.1.8-x86_64.AppImage**. We recommend
[Gear Lever](https://gearlever.mijorus.it/) for integration and updates;
[configure it for Glide](https://github.com/Stem-LG/Glide#gear-lever-recommended)
and allow prereleases.

**Quit the running Glide instance before updating, reopen it, then refresh your
phone's page.** Existing device profiles and preferences are preserved. Enable
four-finger media controls explicitly if you want to try them.

```sh
chmod +x Glide-0.1.8-x86_64.AppImage
./Glide-0.1.8-x86_64.AppImage
```

Use `--appimage-extract-and-run` if FUSE is unavailable. The
[one-time input setup](https://github.com/Stem-LG/Glide/blob/v0.1.8/data/setup/README.md)
still applies. Run Glide as your normal user.

### Compatibility and assets

Portable **x86_64**, **glibc 2.35+**, with bundled GTK/libadwaita. Native gestures
still depend on libinput and the desktop compositor. Use a trusted local network;
the browser connection is HTTP/WebSocket. Licensed under GPL-3.0-or-later.

The AppImage is the runnable download. The source archive includes corresponding
application and dependency sources. Build metadata, dependency inventories and
`SHA256SUMS` are included alongside it.
